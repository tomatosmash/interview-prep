# 保研 / 推免面试准备指南

一套从真实保研面试经历中提炼的面试准备方法论，面向准备推免（保研）面试的本科生。

## 这个项目解决什么

- 不知道几个项目该怎么介绍、面试官会问什么、该怎么准备
- 简历怎么写才"有量化、不吹牛、经得起追问"
- 专业面高频考点有哪些、怎么背才不露怯
- 自我介绍怎么在 30 秒内讲清楚、3 分钟内讲出深度

## 目录结构

## 推荐用法

1. 先读 01，建立「火力分配」和「诚实边界」两个核心观念；
2. 按 02 重做 / 检查自己的简历；
3. 按 03 打磨自我介绍（背熟 30 秒版）；
4. 用 04、05 自测专业面和陷阱题；
5. 面试前过一遍 06 英文。
6. 联系导师 / 套磁看 07——时间上最早开始，面试前 1—2 个月就要动手。

## 核心观念（贯穿全文）

**诚实 > 包装**：复现就是复现、计划就是计划、小组分工不冒领。面试官最欣赏的是"清楚知道自己做了什么、没做什么"的学生，而不是把所有东西都吹成自己的。
